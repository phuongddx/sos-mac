Fix before shipping the redesign

Updater: "check failed" state Bug fix · D3

Today a failed feed check falls through to "Up to date" in green. The redesign has no failed state on the Updater screen until the view model can tell the two apart.

Engine needs
Feed check returns .failed(Error) per app; header count only after all checks finish.
Goes in
Updater results: per-row warning badge and a banner with Try Again.

Uninstaller: real folder sizes Bug fix · D1

Associated folders report the size of the directory entry, not its contents. The prototype shows sizes for the app bundle and single files only; folders read "Folder" and totals read "At least …".

Engine needs
Recursive size for associated directories (same walker as the .app bundle), async per row.
Goes in
Uninstaller review: folder rows show "Measuring…" then the size; the review bar total updates as sizes arrive.

Uninstaller: app is running App only · S8

No check today. Moving a running app to the Trash leaves it running and its support files get recreated.

App needs
NSRunningApplication.runningApplications(withBundleIdentifier:) before the confirm dialog.
Goes in
Uninstall confirm: a "Quit Slack first" step with Quit and Cancel.

Keep results when you leave a screen App only · N1

In the prototype you can leave a module and come back to the same results and selection. Today each view owns its view model, so everything resets (scans are cancelled too).

App needs
Lift view models into an app-level store; scans keep running in the background.
Goes in
Every module. Showing what each module found on the Dashboard or sidebar would also need this, and is a product call (§4.1 lists per-module status as not available).

New data the design would use

Duplicates: thumbnails and similarity Engine

Similar Images pre-selects every non-keep copy with nothing to judge it by (S3). The prototype keeps today's selection and adds a warning banner.

Engine needs
QuickLook thumbnail per file, pixel size, similarity score per pair.
Goes in
Similar Images review: side-by-side compare in the detail panel.

Duplicates: total per set Product call

Derivable from the sizes we already have, so no engine work, but §4.1 lists it as not shown today. Left out of v1 to stay inside the brief.

App needs
Sum of non-keep copies per set in the view model.
Goes in
Group header in the duplicates review: "2 extra copies · 1.3 GB".

Junk: totals per folder and per category Engine

The engine returns files only. The review groups by source rule (which we have), not by folder.

Engine needs
Aggregate per root folder and per rule category.
Goes in
Left column of the Junk review: size per group.

Space Lens: Reveal in Finder, search, % of disk App only

"Open Folder" drills in today (N7). The prototype keeps drill-in on double-click and drops the Finder button.

App needs
NSWorkspace.activateFileViewerSelecting; a search over the scanned tree; % only once a total is known (§4.1).
Goes in
Inspector actions and the path bar.

Cloud: Google Drive, OneDrive, Dropbox Engine

OAuth apps are not registered, so only iCloud works today (D5). The prototype shows Drive as the target design for server-side delete so the confirmation can be reviewed.

Engine needs
Registered OAuth clients, token kept in Keychain across launches, result.failed surfaced (S6).
Goes in
Cloud tabs: Connect state, review, server-side delete confirm.

Protection: real coverage Engine

The database holds one hash (D4). The prototype calls it a "known-signature scan" and shows no coverage, database version or VirusTotal button.

Engine needs
Signature set with a version, YARA rules, optional VirusTotal key flow.
Goes in
Protection start screen: "Signatures updated …" line.

Dashboard: live numbers App only

Today's one-off CPU, memory and thermal reading is shown once. A live refresh only needs a timer on the existing API.

App needs
Poll MachHostStats every 2 s while visible; fix "Memory 99 %" (D2) by counting inactive pages as available.
Goes in
Dashboard system card, menu bar popover.
